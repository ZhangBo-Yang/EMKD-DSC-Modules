# EMKD-DSC Modules

## 中文

| 文件 | 功能 |
| --- | --- |
| `EMKD.py` | 多尺度大核特征提取模块，通过并行卷积分支提取并融合不同感受野的特征。 |
| `DSConv.py` | 动态蛇形卷积模块，包含普通卷积以及沿 x、y 方向的动态蛇形卷积分支。 |
| `requirements.txt` | 记录模块运行所需的 Python 依赖。 |
| `.gitignore` | Git 忽略规则配置文件。 |
| `README.md` | 仓库文件说明。 |

## English

| File | Description |
| --- | --- |
| `EMKD.py` | Multi-scale large-kernel feature extraction module that extracts and fuses features from parallel convolution branches with different receptive fields. |
| `DSConv.py` | Dynamic Snake Convolution module containing a standard convolution branch and dynamic snake branches along the x and y directions. |
| `requirements.txt` | Lists the Python dependencies required by the modules. |
| `.gitignore` | Defines Git ignore rules. |
| `README.md` | Describes the files in this repository. |
